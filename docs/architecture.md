# Method and implementation scope

The C++ engine in `src/DelaunayClusterer.cpp` owns the CGAL triangulation, edge registry, local scales, cluster labels, and verification routines. `include/DelaunayClusterer.h` declares its records and interface. `src/cluster.cpp` implements the static, dynamic, and assignment commands. Python scripts generate inputs and evaluate results; the core executable does not require Python.

## The maintained rule

For the current point set P, construct its 2D Delaunay graph. A vertex's local scale is based on the median length of its incident edges, with a numerical floor in the implementation. Score an edge by its length divided by the geometric mean of its endpoints' scales. Retain edges whose score is at most the threshold tau. Connected components form clusters; components smaller than `max(1, ceil(log2(n)))`, where n is the number of active points, are marked as noise.

The default local-scale selector uses a candidate grid, a component-based objective, eligibility and tie rules, and fixed global constants. It does not tune using supplied ground-truth labels. Other static policies and the Auto selector are evaluated in the static benchmark; Auto is not the dynamic local-scale rule.

## An update

1. Save the old affected neighborhood and change the CGAL triangulation.
2. Refresh a closure of old/new neighborhoods, local scales, edge scores, and retained flags.
3. Attempt local relabeling and update the spatial bucket registry.
4. Traverse the retained graph to check component membership, noise flags, and uniqueness of non-noise cluster identifiers. If the guard fails, fully relabel the refreshed graph.

The bucket grid records locality; it does not define cluster membership for the maintained local-scale rule. Locality/latency claims do not extend to every optional static policy.

The threshold selected from the base points is **frozen**, but scales, scores, connectivity, and the noise cutoff still change. The target is `Fit(P_t, tau_initial)`, up to the numbering of cluster identifiers. A fresh `Fit(P_t)` that reselects tau can disagree substantially without any maintenance error. The theoretical statement assumes at least three points in general position before and after an operation; observed behavior on degenerate adversarial cases does not broaden that theorem. Coincident insertions/movements are handled as no-ops by the maintained implementation.

## Cost and verification

Graph traversal is linear in active vertices and retained edges. The current implementation also uses arrays indexed by allocated point records, including inactive records. Its guard therefore has an expected `O(N+n)` bound in the planar setting, where N counts allocated records and n counts active points. Long sessions with many insertions/deletions can grow N. The implementation does not establish polylogarithmic update time or million-point throughput.

`--verify-dynamic` independently rebuilds a reference and compares the retained edge set, spatial-index registry, and point partition after updates. It is an offline verifier, distinct from the production guard. The verifier checks discrete state rather than every stored floating-point score. Keep it enabled for correctness checks and disabled for timed update comparisons.

## Baselines and evaluation

The C++ DBSCAN comparator implements a grow-only union-find mode, an exact incremental mode, and a from-scratch reference. Grow-only maintenance can miss splits after deletion or movement. Agreement with a method's own full recomputation measures faithfulness; ARI/NMI against known synthetic labels measures external clustering quality. Do not interpret ARI=1 against a same-rule reference as perfect semantic clustering.

The real catalog correction and delayed-withdrawal streams are modeled workloads over real data. AIS movements come from observed consecutive vessel positions; decimation, timeouts, and stream construction are experimental choices. Earthquake declustering removals are generated by the workload's declustering rule. These distinctions matter when interpreting applicability.
